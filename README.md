# スーパーミケの大冒険

ブラウザで遊べるマリオ風アクションゲーム。単一HTMLファイル、PC・スマホ対応、全6ステージ。

**▶ [遊ぶ](https://tg2032.github.io/super-mike/)**

## 操作

| | 移動 | ジャンプ | ダッシュ | その他 |
|---|---|---|---|---|
| PC | ← → / A D | SPACE / ↑ / W / Z | SHIFT / J | P: ポーズ、M: 音 ON/OFF |
| スマホ | 画面の ◀ ▶ | JUMP | RUN | II: ポーズ（横向きでプレイ） |

## 特徴

- 敵を踏む（連続で得点アップ）、キノコで巨大化、ブロック破壊、コイン50枚で1UP
- 敵: ポコ / トビ（跳ねる）/ バタ（飛ぶ）/ トゲゾー（踏めない）
- 仕掛け: トゲ、バネ、動く足場
- ステージ選択（クリアで解放）、ハイスコア保存
- 効果音・BGMは外部ファイルなし（WebAudioで合成）
